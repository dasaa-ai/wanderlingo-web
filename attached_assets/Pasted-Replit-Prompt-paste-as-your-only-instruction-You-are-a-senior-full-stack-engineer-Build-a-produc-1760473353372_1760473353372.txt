Replit Prompt (paste as your only instruction)

You are a senior full-stack engineer. Build a production-ready web-only MVP for an AI translation companion called WanderLingo (you may keep the internal codename MenuSnap). The app is mobile-responsive and deployed from one repo.

Core value

Instantly translate menus, signs, and documents from the browser camera or image upload.

Travel Chat: user types/speaks in any language; reply is generated in a chosen output language; show dual view (source + target).

Library: all translations (image, text, chat) are saved, searchable, taggable, with lightweight offline access.

Stack

Web framework: Next.js (App Router, TypeScript).

UI: Tailwind CSS, shadcn/ui, Lucide icons.

State/Data: React Query (TanStack Query) + minimal Zustand store for UI prefs.

Auth/DB/Storage: Supabase (email/password + OAuth), Postgres, storage buckets.

Payments: Stripe Checkout + Billing Portal (monthly, yearly, lifetime); test webhooks.

Analytics: PostHog (feature events + paywall funnels).

Internationalization: next-intl with JSON message files.

OCR: Tesseract.js (browser) with a server fallback API route.

Speech: Web Speech API for TTS; Whisper API (OpenAI) for STT via server route (optional toggle).

Translation (swappable adapters):

Primary: OpenAI GPT-4o-mini for short/medium text and menu reasoning (allergens, veg/vegan).

Fallback for bulk: DeepL API adapter (optional env).

Offline: Service Worker + IndexedDB (idb library) for local cache of Library items and “recent phrases”.

Create a clean provider interface:
